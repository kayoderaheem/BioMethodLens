# Changelog

All notable changes are documented here.

## 0.1.0 — 2026-09-04

- Introduced the BioMethodLens name and evidence-linked review contract.
- Added 18 universal and bioinformatics-specialist lenses.
- Added transparent minimal, balanced, and conservative routing modes.
- Added concurrent provider execution with partial-failure recovery.
- Added strict JSON Schema output and dependency-free semantic validation.
- Added deterministic report assembly, conservative deduplication, and run manifests.
- Added an OpenAI Responses API adapter with storage disabled by default.
- Added an offline demonstration manuscript and provider.
- Added researcher documentation, privacy guidance, extension guidance, and automated tests.
